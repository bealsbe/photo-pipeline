# Barlow Pipeline

These are the Regular, Medium, SemiBold and Bold styles of [Barlow](https://github.com/jpt/barlow)
by Jeremy Tribby, licensed under the SIL Open Font License 1.1 (`OFL.txt`).

Two changes were made for Photo Pipeline:

- Barlow's tabular figures (the `tnum` feature) replace its proportional ones, so the digits line up
  in columns and counters don't shift as they change.  The app's text renderer can't turn OpenType
  features on, so they are built into the font.
- The family is renamed "Barlow Pipeline" so it can't be confused with a stock Barlow installed on the
  system.
